# ADR-003：知识库改为 Personal Wiki，技能增加自挖掘

## 状态

已采纳（设计）。存储与 API 仍是 Phase 12 卡片，按本 ADR 迁移。

## 背景

Phase 12 用五类经验卡片做跨栈记忆，能复用步骤，但分不出「决策依据」和「操作流程」，召回时权重相同。技能只有手工编写和目录扫描，成功任务不会变成下次可调用的做法。

Personal Wiki 方案把记忆分成事实、决策、流程三层，并给决策层更高召回权重。自动技能方案把成功会话收成 `SKILL.md`，验证通过后才进入调用。

## 决策

1. 中心知识库改为三层 Wiki：L2 模式与决策 ×3.0、L3 流程与工具 ×1.2、L1 事实 ×1.0。`notes` 默认不召回。子目录与 Personal Wiki v1.0 设计态一致。
2. 写入和召回都经过同一张路由表。旧卡片 kind 保留可读并映射到层。新写入使用 `layer` + 子目录。
3. 任务上挂五步：高风险门禁、决策前软召回、写入前打标、结束后复盘、跨源查询。软召回可关。自动召回只对高风险生效。
4. 技能正文仍在运行时目录。中心增加五段引擎：捕获、提炼、验证、存储、检索。任务成功只捕获；只有显式标记才提炼。`draft` 不注入。验证失败三次移入 `_archive`。检索用关键词加向量，并套用与 Wiki 相同的层权重。
5. Wiki 与技能互相只留指针，不复制全文。

## 后果

- 检索会优先抬出决策和教训，流程和事实退居其次。
- 技能库只会在人确认后变长，避免一次成功就污染调用列表。
- Phase 12 的脱敏、Outputs 分离、Session 原文默认不入库，继续有效。
