# ADR-004：多端协议与 PC 自治边界

- 状态：已采纳
- 日期：2026-11-03

## 决策

1. **目标设计真源**：[guide/guide from codex/multi-end-design.md](../guide/guide%20from%20codex/multi-end-design.md)。`architecture.md` 与 README 描述当前源码行为；冲突时按目标设计修订实现与文档。
2. **部署 profile**：`cloud` / `full` / `edge`。`cloud` 协调器执行槽位为 0，不隐式启用本机 CLI；独立云端 worker 另进程挂接。
3. **身份五元组**：Device / Client / Channel / Node / Agent 分表或分角色；同一物理设备可同时挂执行 Node 与语音 Channel，不再用 `mode=voice` 与连接器互斥。
4. **任务归属**：`owner_center_id` + 稳定任务 ID；本地创建归本地中心，云端创建归云端；同步副本不改归属。
5. **协议**：生产逐步迁到 `GET /api/v2/openapi.json` 契约与可靠信封；v1 fleet 保留过渡兼容。
6. **Super-agent**：借鉴 DeepSeek Harness 角色分离（Router 不持工具、Worker 在节点、Watchdog 不扩权），不引入其 TypeScript 运行时。对照见 [guide/super-agent-alignment.md](../guide/super-agent-alignment.md)。

## 后果

- 桌面关窗不停止节点服务（见 ADR-002 修订）。
- 语音终端登记走 Channel，不再占用/覆盖执行节点名册行。
- 跨中心 outbox 必须真实投递后才可宣称闭环。
