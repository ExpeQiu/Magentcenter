# ADR-001：知识库采用卡片内容模型

## 状态

被 [ADR-003](./ADR-003-知识库与技能.md) 取代内容模型。脱敏、原文默认不入库、Outputs 只存指针仍然有效。

## 背景

原知识库将任务全文与 Session 消息直接向量化，噪声大、难复用；OpenClaw/Hermes 已有 SOUL/MEMORY/Skills，中心库若再存人格与原文会污染检索。

## 决策

1. 中心知识库真源为五类卡片：Playbook / Precedent / Incident / ArtifactRef / SharedFact。
2. Session/任务原文仅作可选 `archive`，默认不参与检索与注入。
3. 任务完成规则蒸馏；任务创建前 Top-K 注入 `system_prompt`。
4. Outputs vault 保持独立只读；KB 只存产物指针。

## 后果

- 检索结果更短、可溯源；Mock 下可验证注入闭环。
- 蒸馏初期为规则摘要，后续可换 LLM 蒸馏而不改 schema。
